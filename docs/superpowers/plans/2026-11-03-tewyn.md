# Tewyn Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `tewyn` command: a local library of GitHub skill links, a per-project pin at a commit, agent symlinks, and an on-demand update report.

**Architecture:** One Go module. `internal/library` owns `library.json`. `internal/source` turns a GitHub tree URL plus a file list into a group, and a git-backed `Tree` lists and downloads folders. `internal/project` owns `.tewyn/config.json` and apply order. `internal/agents` owns the three symlinks. `internal/update` writes the report. `internal/tui` is a pure key-driven model; `cmd/tewyn` parses flags and runs Bubble Tea around that model. Tests inject a fake `Tree` and never call GitHub.

**Tech Stack:** Go 1.22, standard library, `git` on PATH for the real `Tree`, `github.com/charmbracelet/bubbletea` for the terminal loop only.

**Spec:** `docs/superpowers/specs/2026-11-03-tewyn-design.md`

## Global Constraints

- The command name is `tewyn`. Module path is `tewyn`.
- Library path is `$XDG_CONFIG_HOME/tewyn/library.json` when `XDG_CONFIG_HOME` is non-empty, otherwise `$HOME/.config/tewyn/library.json`. Never `~/Library/Application Support`.
- A skill URL belongs to one group. The tool never writes an empty group.
- A project holds one skill per name. The library may hold the same name twice when the URLs differ.
- Project state is `.tewyn/config.json` and `.tewyn/skills/<name>/` in the project directory.
- Agent links are relative symlinks to `../.tewyn/skills` at `.claude/skills`, `.cursor/skills`, and `.agents/skills`.
- The tool does not write a gitignore and does not run `git commit` or `git add` on the user's project. The `Tree` may invoke `git` to fetch and archive.
- Add errors and the missing-config error go to stderr as `error: <message>`. Add success and the update report go to stdout.
- Report SHA abbreviations are 7 hex characters. `config.json` stores the full SHA.
- Name-clash text is `two skills named "<name>" cannot both exist`.
- A blocked agent symlink's text is `<Agent>: <rel> is not a symlink to .tewyn/skills`.
- A missing skill path's reason is `path changed`.
- There is no repair screen, no regroup command, and no marketplace.

## Review Focus

These are the failures most likely to ship wrong. Each has a test in the task that owns it.

- A skill path that is gone at the branch tip must stay on disk at the old commit, with `error` set to `path changed`. Test: `TestPathChangedLeavesSkill` in Task 7.
- Deleting one `brainstorming` and adding a different skill of that name must delete first and then download. Test: `TestApplySwapSameName` in Task 5.
- `.claude/skills` already being a real directory must be left untouched, and the error must name Claude. Test: `TestRealDirectoryIsLeftAlone` in Task 6.
- A failed or cancelled download must not replace a skill folder that is already there. Test: `TestDownloadFailureLeavesDest` in Task 4 and `TestQuitCancelsDownload` in Task 9.
- A URL whose folder contains `SKILL.md` is one skill, even when a child folder also contains `SKILL.md`. Test: `TestFolderWithSkillMDIgnoresChildren` in Task 2.
